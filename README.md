# Armería — Base de datos de armas de Blood Strike.

Sitio creado casi en su totalidad por vibe-codding, todos los bugs o errores reportados serán tomados en cuenta.
Este proyecto fué diseñado con el fin de informar sobre el cambio histórico que han sufrido las armas en Bloodstrike.

# Cómo colaborar en el desarollo o correción de datos.

Para ser participe envíame un MD a mi [Discord](https://discord.com/invite/66wMxwsn) personal.
